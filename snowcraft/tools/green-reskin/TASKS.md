# green 캐릭터 리스킨 — 수동 작업 가이드

snowcraft의 **green 팀(상대) 캐릭터**를 새 컨셉(예: 핑크 토끼)으로 직접 교체하기 위한 안내서입니다.
red playable 캐릭터는 건드리지 않습니다.

## 핵심 사실

- 게임이 실제로 렌더링하는 건 `public/assets/sprites/green/1.png ~ 98.png` (98 프레임)입니다.
  (`greendudie_body.png` 450×200 시트는 manifest에 없어 로드되지 않는 **사용 안 되는 파일**입니다. 무시하세요.)
- **98 프레임 중 실제로 다른 이미지는 19개뿐**입니다. 나머지 79개는 이 19개의 복사본입니다.
  → 그래서 **19개만 그리면** 스크립트가 98개로 자동 복사합니다.
- 이 19개가 곧 `greendudie_body.png` 시트에 보이던 8 + 7 + 4 = 19 포즈입니다.

## 작업 순서 (요약)

1. `tools/green-reskin/sources/` 안의 **19개 PNG를 새 캐릭터로 교체**합니다.
   (파일명은 그대로 두세요. 예: `8.png` → `8.png`)
2. `node tools/green-reskin/build.mjs` 실행 → 98 프레임 자동 생성 + `index.json` 자동 갱신.
3. `npm run dev` 로 게임 확인 → `npm run test && npm run build` 로 검증.

## 그릴 때 규칙 (중요)

- **투명 배경 PNG**로 저장하세요. (배경색/체커보드 금지)
- **발이 이미지의 하단-가운데**에 오도록 배치하세요. 렌더러가 "이미지의 bottom-center"를 캐릭터의 발 위치로 삼습니다. (정밀 좌표 불필요)
- **19개 전체에서 캐릭터 몸 크기를 일정하게** 유지하세요. 한 포즈만 크거나 작으면 게임에서 애니메이션이 들썩입니다. 시드로 들어있는 원본 프레임의 캐릭터 크기를 기준으로 삼으면 좋습니다.
- 이미지 크기는 **원본과 비슷한 작은 픽셀 크기**(대략 40~70px)를 권장합니다. 크게 그렸다면 저장 전에 비슷한 크기로 줄이세요.
  - 안전 한도: **height는 반드시 170px 미만**이어야 합니다. (그 이상이면 앵커가 깨집니다. 스크립트가 경고를 띄웁니다.)
- 좌우 방향은 **원본 프레임과 같은 방향**(대체로 왼쪽을 향함)으로 맞추세요. `reference/<n>_x6.png`(6배 확대본)로 원본 포즈/방향을 확인할 수 있습니다.

전체 그룹 정의(어느 프레임이 어느 소스로 복사되는지)는 `groups.json` 참고.

## 스크립트 사용법

```bash
# 미리보기 (실제 변경 없음) — 어떤 소스가 몇 프레임으로 퍼지는지 + 크기 경고 확인
node tools/green-reskin/build.mjs --dry

# 실제 적용 — sources/*.png 를 98 프레임으로 복사 + index.json w/h 갱신
node tools/green-reskin/build.mjs
```

- `sources/` 에 일부 파일만 바꿨다면, 바꾼 그룹만 새 이미지로 퍼지고 나머지는 기존 프레임이 유지됩니다.
- 특정 그룹의 `sources/<rep>.png` 를 지우면 그 그룹은 건너뜁니다(경고 출력, 기존 프레임 보존).
- `index.json` 의 `footX`/`footY`/`labels` 는 절대 바뀌지 않습니다. `w`/`h` 만 실제 이미지 크기로 갱신됩니다.

## 검증

```bash
npm run dev      # 브라우저에서 START 클릭 → green이 새 캐릭터로 보이는지 확인
npm run test     # 274개 테스트 통과해야 함
npm run build    # tsc + vite 빌드 성공해야 함
```
