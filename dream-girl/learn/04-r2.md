# 04. R2

```bash
cf r2 objects put images/fantasy/f01.jpg --bucket-name dream-girl \
  --file public/images/fantasy/f01.jpg --content-type image/jpeg
cf r2 objects list --bucket-name dream-girl
```
전체 업로드: `npm run upload:images` ([scripts/upload-images-r2.sh](../scripts/upload-images-r2.sh)).

Worker 읽기:
```js
const obj = await env.IMAGES.get("images/fantasy/f01.jpg");
const h = new Headers(); obj.writeHttpMetadata(h);
h.set("Cache-Control", "public, max-age=31536000, immutable");
return new Response(obj.body, { headers: h });
```
이미지가 바뀌면 **키(파일명)를 바꿔** 캐시를 무효화하세요 (immutable 이므로).
