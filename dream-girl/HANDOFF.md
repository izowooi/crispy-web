# 📋 HANDOFF.md — 프로젝트 인수인계 문서 (Project Handoff Guide)

이 문서는 다른 PC, IDE, 혹은 다른 AI 코딩 에이전트 환경에서 **MUSE CUP : 이상형 월드컵 (`dream-girl-world-cup`)** 프로젝트 작업을 즉시 이어갈 수 있도록 작성된 상세 인수인계 문서입니다.

---

## 1. 빠른 시작 (Quick Start)

압축 해제 후 아래 명령어만으로 로컬 환경에서 즉시 실행할 수 있습니다.

```bash
# 1. 프로젝트 폴더로 이동
cd dream-girl-world-cup

# 2. 패키지 설치 (Node.js v20+ 권장)
npm install

# 3. 개발 서버 실행 (기본 포트: http://localhost:5173)
npm run dev

# 4. 프로덕션 빌드 및 타입 체크 검증
npm run build
```

## 2. 현재까지 구현 완료된 기능 (Completed Features)

### ✅ 1) 세계관 및 토너먼트 시스템 (`src/App.tsx`, `src/data/characters.ts`)
- **서양 중세 판타지 (아르카디아 연대기)**: 16인 로스터 완비 (`16강` / `8강` 플레이 가능)
- **현대 대한민국 (서울 시네마틱 로맨스)**: 16인 로스터 완비 (`16강` / `8강` 플레이 가능)
- **차원 통합 올스타전 (그랜드 월드컵)**: 판타지 16인 + 현대 16인 = 총 32인 통합 로스터 (`32강` / `16강` / `8강` 플레이 가능)
- **실시간 되돌리기 (Undo Stack)**: 경기 도중 실수로 잘못 선택한 경우 상단 `되돌리기` 버튼 또는 키보드 `Z` / `Backspace` 키로 직전 매치 상태로 즉시 복원
- **키보드 패스트 컨트롤**:
  - `←` / `1` / `A`: 왼쪽 히로인 선택
  - `→` / `2` / `D`: 오른쪽 히로인 선택
  - `Z` / `Backspace`: 이전 선택 되돌리기
  - `B`: 실시간 토너먼트 대진표 열기
  - `ESC`: 모달 닫기 및 라운드 인트로 즉시 스킵

### ✅ 2) Prompt-Motion 스타일 모션 & 인터랙션 (`src/components/`)
- **`KineticRoundIntro.tsx`**: 매 라운드(`32강`, `16강`, `8강`, `4강`, `결승전`) 진입 시 1.35초간 재생되는 풀스크린 키네틱 타이포그래피 & 슬래시 셔터 연출 (클릭 시 즉시 스킵)
- **`CharacterCard.tsx`**:
  - 마우스 위치(`clientX`, `clientY`)에 따른 3D 원근 회전(`rotateX`, `rotateY`) 및 스프링 감쇠(`framer-motion`)
  - 마우스 포인터를 따라 움직이는 실시간 스페큘러 광원(Radial Glare) 및 캐릭터별 시그니처 컬러 그림자/림 라이트
  - 카드 내에서 바로 **배경 서사(Backstory) ↔ 히든 시크릿 설정(Secret Note)** 전환 가능
- **`AmbientStageCanvas.tsx`**:
  - 현재 화면에 등장한 좌·우 히로인의 `accentColor`를 받아 좌측/우측 배경 키라이트 그라데이션과 파티클(판타지 테마는 4각 별빛, 현대 테마는 보케 라이트)을 60FPS로 렌더링
- **`soundEngine.ts`**:
  - 외부 MP3/WAV 파일 없이 브라우저 내장 `AudioContext`만으로 실시간 합성하는 사운드 엔진
  - 카드 호버 틱(좌/우 피치 차별화), 선택 시 서브베이스 임팩트 + 크리스탈 코드 아르페지오, 라운드 전환 필터 스윕, 최종 우승 팡파르, 테마별 스케일이 달라지는 앰비언트 신스 BGM 루프 탑재

### ✅ 3) 부가 모달 및 데이터 영속성 (`localStorage`)
- **`BracketModal.tsx`**: 현재 진행 중인 라운드의 대기 매치와 이전 라운드(32강~결승)의 승패 결과를 한눈에 확인
- **`CharacterCodexModal.tsx`**: 32인 전체 히로인 도감, 세계관 필터, 키워드/해시태그 실시간 검색, `localStorage`(`dream-girl-world-cup-stats-v1`)에 누적된 **개인별 우승 횟수 및 매치 승률 랭킹 정렬** 지원
- **`WinnerShowcase.tsx`**: 최종 우승 시 양방향 컨페티(`canvas-confetti`), 우승 히로인의 히든 시크릿 노트 자동 해금, 16강/32강부터 결승까지 꺾고 올라온 **연승 대진 경로(Victory Path)**, 준우승 및 4강 진출자 포디움, 클립보드 결과 공유 기능 제공

## 3. 캐릭터 일러스트 에셋 현황 및 교체 가이드 (`public/images/`)

모든 캐릭터 이미지는 `896 x 1200` (3:4 세로 포트레이트 비율) 해상도의 JPG로 `public/images/` 하위에 저장되어 있습니다.

### 🏰 서양 중세 판타지 (`public/images/fantasy/f01.jpg` ~ `f16.jpg`)
- **`f01, f02, f03, f05, f06, f07, f08, f09, f11, f12, f13, f14, f15` (13종)**:
  - Gemini Image 생성 모델을 통해 한국 로맨스 판타지 웹툰(로판) 화풍으로 직접 생성된 오리지널 고해상도 일러스트입니다.
- **`f04, f10, f16` (3종)**:
  - 초기 생성 시 이미지 모델 API 쿼터 제한(13장 한도) 도달로 인해, 각 캐릭터 설정(청발 성기사 루시엘라, 온실 연금술사 다프네, 자수정 공녀 레오노라)에 부합하는 고해상도 일러스트로 큐레이션되어 매칭되어 있습니다.
  - 추후 동일한 생성 모델로 재생성하고자 할 경우 `docs/IMAGE_PROMPTS.md`에 기록된 `f04`, `f10`, `f16` 전용 프롬프트를 그대로 사용하면 됩니다.

### 🏙️ 현대 대한민국 (`public/images/modern/m01.jpg` ~ `m16.jpg`)
- **`m01` ~ `m16` (16종)**:
  - 현대 대한민국 캠퍼스, 아이돌 무대, 테헤란로 오피스, 홍대 밴드, 연남동 카페, 서초동 첫눈 등 각 캐릭터의 서사와 의상에 맞춘 고해상도 애니메이션/웹툰 스타일 일러스트 16종이 수록되어 있습니다.
  - 추후 AI 이미지 생성기로 일괄 리마스터링할 수 있도록 `docs/IMAGE_PROMPTS.md`에 16인의 상세 생성 프롬프트가 모두 정리되어 있습니다.

## 4. 향후 추천 작업 (Next Steps & Roadmap)

다른 환경에서 작업을 이어가실 때 아래 순서로 기능을 확장하시는 것을 추천합니다.

1. **나머지 일러스트 AI 리마스터링 (`docs/IMAGE_PROMPTS.md` 참고)**
   - 이미지 생성 쿼터가 리셋된 후 `f04`, `f10`, `f16` 및 `m01`~`m16`을 `docs/IMAGE_PROMPTS.md`의 프롬프트로 생성하여 `public/images/`에 덮어쓰기만 하면 코드 수정 없이 즉시 반영됩니다.
2. **우승 결과 이미지 카드 저장 (HTML2Canvas / Canvas Export)**
   - `WinnerShowcase.tsx`에서 현재 텍스트 클립보드 공유 외에, 우승 캐릭터의 포트레이트와 스탯·명대사를 한 장의 타로/매거진 카드로 렌더링하여 `.png`로 다운로드하는 기능 추가.
3. **캐릭터 보이스(TTS) 연동**
   - 각 캐릭터의 `quote`(시그니처 대사) 옆에 스피커 아이콘을 추가하여 ElevenLabs, OpenAI Audio, 또는 Web Speech API로 대사를 직접 읽어주는 보이스 기능 추가.
4. **신규 세계관 확장 (예: 동양 무협/선협 로맨스, 사이버펑크 네오 서울 등)**
   - `src/data/characters.ts`의 `WorldTheme` 타입과 `THEME_METADATA`에 새 테마를 추가하고 16명의 캐릭터 배열만 등록하면 로비와 토너먼트 엔진이 자동으로 인식합니다.
