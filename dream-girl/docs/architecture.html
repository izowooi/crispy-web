01 · Stack

네 개의 층, 한 번의 배포

FRONTEND

React SPA (CSR)

Vite로 빌드한 정적 번들. 토너먼트 상태 머신, 스프링 물리 카드, Canvas 포토카드 내보내기.

COMPUTE

Cloudflare Worker

/api/* 와 /images/* 만 Worker가 먼저 받고, 나머지는 정적 에셋 + SPA 폴백.

DATABASE

D1 (SQLite)

캐릭터별 승/전/우승 집계, 토너먼트 기록, 공유 링크 스냅샷. batch()로 원자적 갱신.

STORAGE

R2 버킷

64장 일러스트를 immutable 캐시 헤더와 함께 서빙. 이그레스 요금 없음.

DELIVERY

cf CLI 배포

cloudflare.config.ts 한 파일에 바인딩과 도메인 선언 → cf deploy.

ART

Nano Banana

같은 화풍의 로판/현대 웹툰풍 일러스트 4세트 × 16명.
