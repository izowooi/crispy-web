      드리프트 — 텍스트 이외 영역 기준, 모델 출력이 원본 대비 이동/확대된 최대 픽셀 (측정만, 보정하지 않음).

      PSNR(변경 외 영역) — 모델이 바꾸지 않은 영역이 원본과 얼마나 같은지. 높을수록 동일 (30dB↑ 매우 유사).
