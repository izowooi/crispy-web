# 피드 및 카테고리 기능 기획서

## 1. 개요

사용자가 업로드한 피드를 체계적으로 정리하고 탐색할 수 있도록 카테고리 구조(대분류 / 중분류) 기능을 추가한다.
기존 피드 기능은 변경 없이 유지하며, 카테고리 탭에서만 카테고리 기반 탐색 기능을 제공한다.

---

# 2. 용어 정의

| 용어  | 설명                            |
| --- | ----------------------------- |
| 피드  | 사용자가 업로드하는 기본 콘텐츠 단위 (이미지 중심) |
| 카테고리  | 피드를 카테고리 단위로 모아볼 수 있는 탭       |
| 대분류 | 상위 카테고리                       |
| 중분류 | 대분류 하위 카테고리                   |
| 관리자 | 카테고리를 관리할 수 있는 권한을 가진 사용자     |

---

# 3. 기능 구조

## 3.1 피드

* 기존 기능 유지
* 피드 업로드 시 **카테고리 선택 기능 추가**

선택 가능한 항목

* 대분류 선택
* 중분류 선택

선택 규칙

| 항목           | 가능 여부 |
| ------------ | ----- |
| 대분류만 선택      | 가능    |
| 대분류 + 중분류 선택 | 가능    |
| 중분류만 선택      | 불가능   |

---

# 4. 관리자 기능

## 4.1 카테고리 관리

관리자는 다음 기능을 수행할 수 있다.

### 대분류 관리

* 대분류 생성
* 대분류 수정
* 대분류 삭제

### 중분류 관리

* 특정 대분류 하위에 중분류 생성
* 중분류 수정
* 중분류 삭제

카테고리는 관리자가 자유롭게 커스텀 생성 및 수정이 가능하다.

---

## 4.2 기존 피드 카테고리 수정

관리자는 이미 업로드된 피드에 대해 다음 작업이 가능하다.

* 대분류 추가
* 중분류 추가
* 카테고리 수정
* 카테고리 삭제

---

# 5. 카테고리 탭 기능

카테고리 탭에서는 카테고리 기반 탐색 기능을 제공한다.

## 5.1 카테고리 탐색 구조

1단계
→ 대분류 선택

2단계
→ 해당 대분류의 중분류 목록 표시

3단계
→ 중분류 선택 시 해당 피드 표시

---

## 5.2 피드 표시 방식

### 대분류 선택 시

* 해당 대분류에 포함된 **모든 피드 표시**
* 중분류에 포함된 피드도 함께 표시

### 중분류 선택 시

* 해당 중분류에 속한 피드만 표시

---

## 5.3 보기 방식

카테고리에서는 다음 방식으로 콘텐츠를 표시한다.

* 이미지 중심 그리드 형태
* 피드 선택 시 상세 피드 화면 이동

---

# 6. 데이터 구조 (초안)

### Category (대분류)

| 필드         | 설명      |
| ---------- | ------- |
| id         | 카테고리 ID |
| name       | 카테고리 이름 |
| created_at | 생성일     |

---

### SubCategory (중분류)

| 필드          | 설명        |
| ----------- | --------- |
| id          | 중분류 ID    |
| category_id | 상위 대분류 ID |
| name        | 중분류 이름    |

---

### Feed

| 필드             | 설명                |
| -------------- | ----------------- |
| id             | 피드 ID             |
| content        | 피드 내용             |
| category_id    | 대분류 ID            |
| subcategory_id | 중분류 ID (optional) |

---

# 7. UX 흐름

## 피드 업로드

1. 이미지 업로드
2. 내용 작성
3. 대분류 선택 (optional)
4. 중분류 선택 (optional, 대분류 선택 시만 가능)
5. 업로드

---

## 카테고리 탐색

1. 카테고리 탭 진입
2. 대분류 선택
3. 중분류 선택 (optional)
4. 피드 목록 확인

---

# 8. 예시

대분류

* 년도
* 여행

중분류

년도

* 2025
* 2026

여행

* 제주도
* 호주

사용 예

피드
사진: 2026년 박수아

선택
대분류: 2026년
중분류: 박수아

→ 카테고리 > 2026년 > 박수아 에 표시
