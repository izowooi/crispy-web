# Big Five 심리 성향 검사 웹앱 계획서

## 1. 목표

`big-five` 폴더는 독립 실행 가능한 Next.js 웹앱입니다. 사용자는 180개 자기보고식 문항에 응답하고, 완료 후 Big Five 5대 요인과 30개 세부척도 결과를 0-100 점수, 밴드, 레이더 차트, 막대 차트로 확인합니다. 이 문서와 `QUESTIONNAIRE.md`만 보아도 동일한 웹앱을 다시 구현할 수 있도록 데이터 구조, 채점식, 화면 흐름, 테스트 기준을 함께 둡니다.

## 2. 근거 조사와 문항 작성 원칙

- [IPIP 공식 사이트](https://ipip.ori.org/)는 International Personality Item Pool의 문항과 척도가 퍼블릭 도메인이며 복사, 편집, 번역, 사용이 가능하다고 안내합니다.
- [IPIP의 척도 찾기 안내](https://ipip.ori.org/Finding_Scales_to_Measure_Particular_Constructs.htm)는 Big Five와 Five-Factor Model의 배경, IPIP-NEO 300문항판, Johnson 2014의 120문항판, Maples et al. 2014의 120문항판을 설명합니다.
- [NIH CDE 페이지](https://www.nih.gov/node/21486)는 IPIP NEO를 120문항 자기보고식 Big Five 도구로 소개하고, 저작권 항목을 `No`로 표기합니다.
- 이 앱의 180문항은 IPIP 원문 복사본이나 직역본이 아니라, 5요인 x 6세부척도 구조를 참고해 새로 작성한 한국어 원문입니다. 따라서 문항 사용과 수정이 쉽고, 나중에 한국어 맥락에 맞춘 파일럿 검증도 가능합니다.

## 3. 검사 설계

총 180문항을 사용합니다. 구성은 5대 요인 x 요인별 6세부척도 x 세부척도별 6문항입니다. 세부척도마다 정방향 3문항과 역방향 3문항을 배치해 일방향 응답 편향을 줄였습니다. 문항당 평균 8-10초, 페이지 이동과 잠시 쉬는 시간을 포함하면 약 24-32분이 걸리므로 30분 검사 분량으로 설계했습니다.

응답 척도는 5점 Likert입니다.

| 값 | 라벨 |
| --- | --- |
| 1 | 전혀 그렇지 않다 |
| 2 | 대체로 그렇지 않다 |
| 3 | 보통이다 |
| 4 | 대체로 그렇다 |
| 5 | 매우 그렇다 |

## 4. 요인과 세부척도

| 요인 | 세부척도 |
| --- | --- |
| 개방성 `O` | 상상력, 미적 감수성, 감정 인식, 변화와 시도, 지적 호기심, 가치 유연성 |
| 성실성 `C` | 유능감, 질서, 책임감, 성취추구, 자기절제, 신중성 |
| 외향성 `E` | 친밀감, 사교성, 자기표현, 활동성, 자극추구, 긍정정서 |
| 우호성 `A` | 신뢰, 정직성, 이타성, 협조성, 겸손, 연민과 공감 |
| 정서적 민감성 `N` | 불안민감성, 분노반응, 침체감, 자의식, 충동성, 스트레스 취약성 |

## 5. 채점 방식

정방향 문항은 사용자의 응답값을 그대로 사용합니다. 역방향 문항은 `6 - 응답값`으로 변환합니다. 이후 문항 점수는 `((변환값 - 1) / 4) * 100`으로 환산합니다.

세부척도 점수는 해당 6문항 평균입니다. 요인 점수는 해당 요인의 36문항 평균입니다. 현재 구현은 부분 응답 상태도 계산할 수 있으나, 결과 화면은 모든 문항 완료 후 표시합니다.

밴드는 다음처럼 해석합니다.

| 밴드 | 범위 |
| --- | --- |
| 낮음 | 0 이상 40 미만 |
| 중간 | 40 이상 66 미만 |
| 높음 | 66 이상 100 이하 |

정서적 민감성은 높을수록 걱정, 긴장, 정서 반응을 더 민감하게 경험한다는 뜻입니다. 낮은 점수는 정서 안정성이 높은 쪽으로 해석할 수 있지만, 이 검사는 비임상 자기이해 도구입니다.

## 6. 데이터 모델

단일 원천 데이터는 `src/data/questionnaire.json`입니다.

```json
{
  "version": "2026-05-28-original-ko-180",
  "responseScale": [{ "value": 1, "label": "전혀 그렇지 않다" }],
  "domains": [
    {
      "id": "O",
      "name": "개방성",
      "englishName": "Openness",
      "color": "#0f766e",
      "facets": [
        {
          "id": "O1",
          "name": "상상력",
          "items": [
            { "id": "O1-01", "keyed": "positive", "text": "..." }
          ]
        }
      ]
    }
  ]
}
```

웹앱은 `src/data/questionnaire.ts`에서 JSON을 평탄화해 `domains`, `facets`, `questionnaireItems`를 제공합니다. 채점 로직은 `src/lib/scoring.ts`에 격리되어 UI 없이 테스트할 수 있습니다.

## 7. 화면 흐름

1. 시작 화면: 검사 분량, 응답 척도, 개인정보 저장 방식, 이어 하기 버튼을 보여줍니다.
2. 검사 화면: 15문항씩 12페이지로 나누어 보여줍니다. 페이지 문항을 모두 응답해야 다음으로 이동할 수 있습니다.
3. 결과 화면: 5대 요인 레이더 차트, 요인별 막대, 선택한 요인의 6개 세부척도를 보여줍니다.
4. 결과 저장: 브라우저에서 JSON 파일로 응답과 점수를 내려받을 수 있습니다.
5. 초기화: 로컬 저장소와 현재 응답을 지웁니다.

응답은 브라우저 `localStorage`에만 저장합니다. 서버 저장, 외부 API, 인증, 데이터베이스는 현재 범위에 포함하지 않았습니다.

## 8. 구현 파일 맵

| 파일 | 역할 |

| `docs/QUESTIONNAIRE.md` | 재구현용 전체 검사지 |

## 9. TDD와 검증 전략

먼저 실패하는 Vitest 테스트를 작성했습니다. 테스트는 5요인, 30세부척도, 180문항, 세부척도별 6문항, 세부척도별 역방향 3문항을 검증합니다. 이후 채점 구현을 추가해 정방향/역방향 응답이 모두 100점으로 환산되는지, 부분 응답에서 누락 문항 수가 정확한지 확인했습니다.

최종 검증 게이트는 다음 순서입니다.

```bash
npm run docs:questionnaire
npm run test
npm run lint
npm run build
npm run pages:build
```

UI 변경이 있으므로 dev server를 띄운 뒤 브라우저로 시작 화면, 검사 응답, 결과 화면, 모바일 폭을 확인합니다.

## 10. 향후 개선

- 표준화 표본을 수집해 백분위와 신뢰구간을 추가합니다.
- 세부척도 간 조합 해석을 별도 규칙 파일로 분리합니다.
- 결과 PDF 또는 이미지 내보내기를 추가합니다.
- 무작위 문항 순서, 주의 확인 문항, 응답 일관성 지표를 추가합니다.
- 실제 연구나 상담 용도로 쓰려면 한국어 문항의 신뢰도, 요인구조, 문항반응 특성을 별도로 검증해야 합니다.
