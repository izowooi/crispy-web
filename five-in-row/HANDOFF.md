- 운영: https://five.zowoo.uk — Worker `five-in-row` + Durable Object `GameRoom` + D1 `five-in-row`(id `d74530fe-…`) + ratelimit `4201`. placement `aws:ap-northeast-2`.
- 출발점: `chess/`(체스 한 판)를 복사해 규칙만 오목으로 바꿨다. 방·좌석 토큰·시계·AI 턴·감정 표현·한도·로비 구조는 체스와 같다. 체스 쪽 결정 이력은 `../chess/HANDOFF.md`를 본다.
- 바뀐 것
  - 규칙: `shared/omok.ts`(15×15, 흑 선, 5목 이상 승리, 쌍삼은 방 옵션: 흑만 금지(기본, 사용자 결정 — 흑이 유리하므로)·모두 금지·모두 허용, 5목이면 허용, 4-4 허용). 서버와 클라이언트가 같은 함수를 쓴다.
  - 흑이 먼저 둔다. `Color`는 그대로 `"b" | "w"`이고, 결과는 `"b" | "w" | "draw" | "*"`.
  - AI 입력: 텍스트 판(X/O), 기보, 후보 점(돌에서 2칸 이내 합법 점). 평가·위협 주석 없음(공정 비교 원칙). 2026-10-21 프로브에서 후보 182개도 세 API 모두 수락.
  - UI: 체스 기물 팔레트를 그대로 쓴 돌 SVG, 나무색 플랫 바둑판, 마지막 수 빨간 점, 5목 줄 강조, 금지점 ×. 모바일은 탭 두 번(미리보기→착수), 마우스는 클릭 한 번.
  - 보드 뒤집기 없음(오목은 대칭). PGN 대신 텍스트 기보 복사.
- 알려진 극단 사례: "흑만 금지"에서 판이 거의 차 흑이 둘 곳이 금지점뿐이면 둘 수 없어 시간패까지 간다(AI 대체 수도 후보가 없음). 매우 드물어 미처리.
- 운영 테스트 대국: `RnasFsaeWD`, `temP4tX2wi`(검증-흑 vs 검증-백), AI 검증 `QkWwqZ4VuD`, `iswVTLtmNp`(취소). 삭제는 사용자 승인 대기.
- 남은 후보: 렌주룰(흑 장목·4-4 금지) 옵션, 수순 번호 표시 토글, 연결 끊김 시 상대 승리 청구, Elo.
