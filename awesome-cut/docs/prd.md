# PRD: awesome-cut

## 제품 개요

**awesome-cut**은 AI 이미지 생성 모델 Nano Banana 2(Gemini 3.1 Flash Image)를 활용해,
사용자가 준비한 캐릭터 시트와 스토리라인을 바탕으로 **3×3 시네마틱 시퀀스 이미지**를 자동 생성하는 웹 앱이다.

- 모델: `gemini-3.1-flash-image-preview` (Nano Banana 2, 고정)
- 출력: 1K 이미지 4장 동시 생성 → 사용자가 1장 선택 후 2K 업스케일 가능
- 레이아웃: 3×3 그리드 고정, 가로(landscape) 모드 전용

---

## 핵심 기능

### 1. 캐릭터 시트 입력
- 드래그앤드롭으로 캐릭터 시트 이미지 업로드
- 최소 1장, 최대 4장 (슬롯 4개 표시)
- 지원 포맷: JPG, PNG, Webp
- 각 슬롯에 캐릭터 역할 레이블 표시 (캐릭터 1 ~ 4)

### 2. 스토리라인 프롬프트 입력
- 텍스트 입력창에 스토리 내용을 자유롭게 입력
- 예시: "경찰인 여자주인공과 군인 남자주인공 사이에 소방서에서 벌어지는 로맨스"

### 3. 시네마틱 스타일 선택
고정 요소인 "3×3 시퀀스" 외, 아래 스타일 중 하나를 선택한다.

| 스타일 | 설명 | 기본값 |
|---|---|---|
| 실사 시네마틱 (Realistic Cinematic) | 영화 같은 실사 촬영 느낌 | O |
| 애니메이션 시네마틱 (Animated Cinematic) | 애니메이션 영화 스타일 | |
| 웹툰 스타일 (Webtoon Style) | 한국 웹툰 그림체 | |
| 수채화 일러스트 (Watercolor Illustration) | 감성적인 수채화 느낌 | |
| 3D CGI 렌더링 (3D CGI Rendering) | 3D 그래픽 렌더링 스타일 | |

### 4. 이미지 생성
- 제출 버튼 클릭 시 동일 프롬프트로 1K 이미지 **4장 동시 생성**
- 생성 중에는 로딩 인디케이터 표시
- 완성된 4장을 2×2 그리드로 결과 화면에 표시

### 5. 업스케일 (2K)
- 결과 이미지 4장 중 **1장만 선택**하여 2K로 업스케일
- 의도적 제한: 한 번에 1장만 업스케일 가능 (API 비용 관리)
- 업스케일된 이미지는 별도 다운로드 버튼 제공

### 6. 일괄 다운로드
- 1K 이미지 4장을 ZIP 파일로 일괄 다운로드 가능

### 7. 재생성
- 동일 설정(캐릭터 + 프롬프트 + 스타일)으로 재생성 버튼 제공
- 또는 캐릭터/스토리라인을 수정 후 재제출 가능

## 사용자 플로우

```
[캐릭터 시트 업로드]
    캐릭터 슬롯(1~4)에 이미지를 드래그앤드롭
         |
[스토리라인 입력]
    텍스트창에 스토리 내용 작성
         |
[스타일 선택]
    드롭다운 또는 라디오버튼으로 시네마틱 스타일 선택
         |
[제출]
    → API 호출: 4장 동시 생성 (1K)
    → 로딩 화면
         |
[결과 표시 — 2×2 그리드]
    ┌──────┬──────┐
    │  #1  │  #2  │
    ├──────┼──────┤
    │  #3  │  #4  │
    └──────┴──────┘
         |
    [선택지 A] 마음에 드는 이미지 1장 선택 → 2K 업스케일 → 다운로드
    [선택지 B] 4장 전체 ZIP 다운로드
    [선택지 C] 재생성 (동일 프롬프트) 또는 수정 후 재제출
```

## UI/UX 요구사항

- **레이아웃**: 1컬럼 세로 스크롤 (모바일 대응)
- **캐릭터 슬롯**: 4개 카드, 비어있는 슬롯은 "+" 아이콘과 드래그앤드롭 힌트 표시
- **프롬프트 입력창**: 여러 줄 지원, 최대 500자
- **스타일 선택**: 라디오 버튼 또는 카드 형태, 스타일명 + 간단한 설명 표시
- **제출 버튼**: 아이콘 버튼 (또는 "생성하기" 텍스트 버튼)
- **결과 그리드**: 2×2, 각 이미지 위에 "업스케일" 버튼 표시 (호버 시 노출 또는 항상 표시)
- **업스케일 선택**: 선택한 이미지에 하이라이트 테두리 → 확인 버튼으로 업스케일 실행
- **오류 처리**: API 오류, 안전 필터 차단 시 사용자 친화적 메시지 표시

## 최종 프롬프트 구성 방식

내부적으로 아래와 같이 최종 프롬프트를 조합한다.

```
"{스토리라인}" 을(를) 담은 3by3 {스타일} 시퀀스를 이미지로 만들어줘.
캐릭터 정보는 첨부된 캐릭터 시트를 참고해.
이미지는 가로(landscape) 모드로 출력해.
```

## API 설계

### POST `/api/generate`
- **입력**: FormData
  - `characters[]`: 캐릭터 시트 이미지 파일 (1~4장)
  - `storyline`: 스토리라인 텍스트
  - `style`: 스타일 ID (`realistic_cinematic` | `animated_cinematic` | `webtoon` | `watercolor` | `3d_cgi`)
  - `count`: 생성 수 (고정: `4`)
- **출력**: JSON `{ images: [{ base64: string, mimeType: string }] }`
- `maxDuration`: 120초 (4장 동시 생성 고려)

### POST `/api/upscale`
- **입력**: FormData
  - `image`: 업스케일 대상 이미지 파일
- **출력**: 업스케일된 이미지 바이너리
- `maxDuration`: 60초

## 제약 사항

- 출력 이미지 방향: **가로(landscape) 모드만 지원**
- 기본 출력 해상도: **1K 고정**
- 업스케일 해상도: **2K**
- 업스케일: **1회 1장 한정** (비용 관리 목적, 의도된 제한)
- 최대 캐릭터 수: **4명**
- 시퀀스 레이아웃: **3×3 고정**
- AI 모델: **Nano Banana 2 고정** (사용자 변경 불가)
