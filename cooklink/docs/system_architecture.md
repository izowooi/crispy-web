# 전체 서비스 아키텍처

## 시스템 흐름

사용자 → 웹앱 → 유튜브 URL 입력 → YouTube API 호출 → 영상 메타데이터 +
자막 수집 → AI 분석 → 레시피 데이터 생성 → DB 저장 → 사용자 화면 표시

------------------------------------------------------------------------

## 구성 요소

### Frontend

-   Next.js
-   React
-   TailwindCSS
-   Responsive UI

### Backend

-   Node.js
-   NestJS

역할

-   API 제공
-   유튜브 데이터 처리
-   AI 요청 관리

### AI Layer

-   Gemini API
-   자막 분석
-   레시피 추출

### Database

-   PostgreSQL

저장 데이터

-   사용자
-   레시피
-   재료
-   태그
-   조리 과정

### Search

-   Meilisearch

빠른 레시피 검색 제공

------------------------------------------------------------------------

## 비용 최적화 전략

1.  YouTube API로 먼저 필터링
2.  자막 기반 분석
3.  동일 영상 캐싱
4.  AI 호출 최소화
