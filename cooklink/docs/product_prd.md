# PRD (Product Requirement Document)

## 1. 제품 목표

유튜브 요리 영상을 레시피 데이터로 변환하고 사용자들이 레시피를 공유할
수 있는 플랫폼 구축.

목표

-   영상 → 구조화된 레시피 데이터 변환
-   커뮤니티 기반 레시피 탐색
-   모바일 친화적인 요리 도구 제공

------------------------------------------------------------------------

## 2. 주요 사용자

1.  요리 초보
2.  자취생
3.  유튜브 레시피 사용자
4.  간단한 요리를 찾는 사용자

------------------------------------------------------------------------

## 3. 핵심 사용자 흐름

1.  사용자 사이트 방문
2.  유튜브 URL 입력
3.  시스템이 영상 분석
4.  레시피 생성
5.  사용자가 저장 또는 공개
6.  다른 사용자 탐색

------------------------------------------------------------------------

## 4. 기능 요구사항

필수 기능

-   유튜브 URL 입력
-   영상 메타데이터 수집
-   자막 추출
-   AI 기반 레시피 분석
-   레시피 저장

커뮤니티 기능

-   레시피 공유
-   태그 기반 검색
-   카테고리 탐색
-   좋아요

------------------------------------------------------------------------

## 5. 비기능 요구사항

-   모바일 최적화
-   빠른 검색
-   AI 비용 최소화
-   동일 영상 캐싱
