# 유튜브 레시피 변환 및 공유 플랫폼 기획서

## 1. 서비스 개요

유튜브 요리 영상을 분석하여 **재료, 분량, 조리 과정**을 자동으로
정리하고, 사용자들이 생성한 레시피를 함께 탐색할 수 있는 플랫폼형 웹
서비스.

핵심 기능 - 유튜브 URL 입력 → 레시피 자동 생성 - 생성된 레시피 저장 및
공유 - 다른 사용자 레시피 탐색 - 태그 / 카테고리 기반 검색

------------------------------------------------------------------------

## 2. 문제 정의

현재 사용자 행동

1.  유튜브에서 요리 영상 검색
2.  영상 시청
3.  재료가 나오는 구간을 찾기 위해 앞뒤 이동
4.  재료와 분량을 따로 기록
5.  요리 중 다시 영상 확인

문제점

-   재료가 영상 중간중간 등장
-   정확한 분량 찾기 어려움
-   레시피 구조가 정리되어 있지 않음
-   요리 중 영상 탐색이 번거로움

------------------------------------------------------------------------

## 3. 해결 방법

사용자가 유튜브 URL을 입력하면

시스템이 다음을 자동 수행

1.  영상 메타데이터 수집
2.  자막 수집
3.  AI 분석
4.  레시피 구조화

결과 출력

-   요리 이름
-   재료 목록
-   재료 분량
-   조리 순서

------------------------------------------------------------------------

## 4. 커뮤니티 기능

사용자가 만든 레시피를 공개하여 플랫폼 내에서 탐색 가능

탐색 기능

-   인기 레시피
-   최신 레시피
-   카테고리 탐색
-   태그 검색

예시 카테고리

-   한식
-   중식
-   일식
-   양식
-   디저트
-   다이어트
-   간단요리

예시 태그

-   파스타
-   볶음밥
-   에어프라이어
-   자취요리
-   5분요리

------------------------------------------------------------------------

## 5. 웹앱 구조

메인 페이지 - 유튜브 URL 입력 - 추천 레시피 - 인기 레시피

레시피 탐색 페이지 - 카테고리 - 태그 검색 - 인기 레시피

레시피 상세 페이지 - 영상 - 요리 이름 - 재료 - 조리 과정 - 태그

------------------------------------------------------------------------
