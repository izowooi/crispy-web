# 실습: 프롬프트를 고쳐 보고 결과 비교하기 (로컬 전용)

> ⚠️ **이 실습은 Claude API 비용이 듭니다.** 사진 한 장을 분석할 때마다 이미지 입력 토큰과 JSON 출력 토큰이 과금돼요.
> 운영 사이트(bm.zowoo.uk)가 아니라 **내 컴퓨터의 로컬 DB**에서만 하세요. `CLAUDE_API_KEY`가 `menu/.env.local`에 있어야 합니다.
> 자동 테스트(`npm test`)는 가짜 클라이언트를 쓰므로 비용이 들지 않습니다 — 그쪽은 마음껏 돌려도 됩니다.

## 준비물

| 항목 | 값 |
|---|---|
| 샘플 사진 | `docs/menu.jpeg` (2026년 10월 식단표) |
| 키 | `menu/.env.local` 의 `CLAUDE_API_KEY=` (**절대 커밋 금지**, 이미 `.gitignore` 대상) |
| 로컬 DB | `npm run db:migrate:local` (한 번만) |

## 실험 1 — 화면으로 한 번 돌려 보기 (제일 쉬움)

```bash
cd menu
npm run db:migrate:local
npm run dev            # http://localhost:3000
```

1. 브라우저에서 새 어린이집을 만든다 (이름·비밀번호는 연습용 아무거나, 예: `연습반` / `demo-1234`).
2. 관리 화면에서 `docs/menu.jpeg`를 선택하고 **AI로 식단표 읽기**를 누른다. (약 30초)
3. 검토 화면에서 **경고 목록**과 날짜별 칸을 원본 사진과 나란히 비교한다.
4. 저장하지 않고 닫아도 된다. (사진은 로컬 R2 에뮬레이터에만 저장됨)

체크할 것:

- [ ] 22일치(평일)가 모두 들어왔나?
- [ ] 알레르기 번호가 이름 뒤에서 `allergens`로 분리됐나? (예: `모듬버섯국5,6` → `모듬버섯국 [5,6]`)
- [ ] 휴원일(한글날 등)이 `closed`로 잡혔나?
- [ ] 노란 경고(요일 불일치, 메뉴 비어 있음)가 실제 오류와 일치하나?

## 실험 2 — 프롬프트 규칙 하나만 바꿔 보기

`src/lib/server/extract.ts` 의 `EXTRACT_SYSTEM_PROMPT`는 규칙 목록입니다. **한 번에 규칙 하나만** 바꾸고 같은 사진으로 다시 돌려 차이를 보세요.

| 바꿔 볼 것 | 기대하는 변화 |
|---|---|
| "괄호 안 대체 메뉴는 하나로 합칩니다" 줄 삭제 | `백김치(백깍두기)` 가 두 항목으로 갈라질 수 있음 |
| "weekday에는 사진에 적힌 요일을 그대로" → "계산해서 채우세요" | 요일 불일치 경고가 사라짐 (= 검증 장치를 스스로 무력화함 ⚠️) |
| 규칙 끝에 "원산지는 비워 두세요" | 모든 날 `origin` 이 `null` |

> 원칙: **바꾸기 전에 "무엇이 틀렸는지"를 사진과 결과로 먼저 확인**하세요. 느낌으로 규칙을 늘리면 서로 충돌하는 규칙이 쌓입니다.
> 끝나면 `git diff src/lib/server/extract.ts` 로 내가 바꾼 부분을 확인하고, 실험용 변경은 직접 되돌리세요.

## 실험 3 — 모델 바꿔 보기

`menu/.env.local` 에 한 줄 추가 (로컬 dev 서버에만 적용됨, 서버를 재시작해야 반영):

```bash
CLAUDE_MODEL=claude-opus-5-5
```

같은 사진을 다시 분석해 **정확도 · 소요 시간 · 토큰 사용량**을 비교합니다. 운영 모델은 `wrangler.jsonc` 의 `vars.CLAUDE_MODEL` 이며 로컬 값과는 별개입니다.

## 토큰 사용량 확인하기 (임시 로그)

`extract.ts` 에서 `response`를 받은 직후에 **임시로** 한 줄을 넣고, 확인한 뒤 지우세요.

```ts
console.log("usage", response.usage); // 확인 후 삭제
```

`input_tokens` / `output_tokens` 가 찍힙니다. 실제 비용 = 토큰 수 × 모델별 단가이며, 단가는 반드시 [Anthropic 가격 페이지](https://www.anthropic.com/pricing)에서 **그 시점의 값**을 확인하세요. (이 문서에는 일부러 숫자를 적지 않았어요. 바뀝니다.)
